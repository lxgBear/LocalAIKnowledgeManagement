# 飞书配置

飞书有两条独立通道：

| 通道 | 作用 | 配置位置 |
|---|---|---|
| Hermes gateway | 收消息、回复、定时推送 | `~/.hermes/.env` |
| 自定义机器人 | 只向群推送 | 群机器人的 webhook |

两条通道使用不同凭据。自定义机器人不能读取群消息。

## 1. 自建应用

在[飞书开放平台](https://open.feishu.cn/app)创建企业自建应用，启用机器人能力，并记录 App ID 与 App Secret。

开通这些权限：

- `im:message`
- `im:message.group_msg`
- `im:message.p2p_msg:readonly`
- `im:chat:readonly`

把应用发布，然后把机器人加入目标群。

事件订阅选择「使用长连接接收事件」，请求地址留空。添加事件 `im.message.receive_v1`。保存订阅方式前，Hermes gateway 必须已经连上。

用户 OAuth 的本地回调地址是 `http://localhost:3000/callback`。它不是事件订阅地址。

## 2. Hermes

```bash
hermes gateway setup
```

在 `~/.hermes/.env` 写入：

```bash
FEISHU_APP_ID=
FEISHU_APP_SECRET=
FEISHU_DOMAIN=feishu
FEISHU_CONNECTION_MODE=websocket
FEISHU_ALLOW_ALL_USERS=false
FEISHU_ALLOWED_USERS=
FEISHU_REQUIRE_MENTION=false
```

`FEISHU_ALLOWED_USERS` 填写本人的 `open_id`。`FEISHU_REQUIRE_MENTION=false` 允许普通群消息进入；设为 `true` 时必须 @ 机器人才会处理。

安装并检查：

```bash
hermes gateway install
hermes gateway status
```

日志在 `~/.hermes/logs/gateway.log`。同一应用不要再启动第二条长连接，否则飞书会随机选择接收端，Hermes 可能收不到消息。

## 3. 自定义机器人

在群中添加自定义机器人，启用签名校验，取得 webhook 与 secret。请求签名：

```text
sign = Base64(HMAC-SHA256(key=timestamp + "\n" + secret, msg=""))
```

请求体包含 `timestamp`、`sign`、`msg_type` 和 `content`。时间戳与飞书服务器相差超过 1 小时会被拒绝。

## 4. 安全

App Secret、Verification Token、webhook、签名密钥和用户 `open_id` 只放本机环境变量或本地敏感文件，不提交到仓库。
