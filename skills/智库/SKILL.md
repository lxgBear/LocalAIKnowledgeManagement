# 智库

只回答规则判定。不写文件，不调用命令，不提炼正文。

| 输入 | 判定 |
|---|---|
| URL、网页正文、书摘、口述、粘贴文本、单词 | `F1` 消化 |
| 询问已有记录 | `F3` 检索 |
| 要求体检或整理 | `F4` lint |
| 要求迁移旧库 | `F6` 迁移 |

返回 JSON：`{"rule":"F1","reason":"这是一条待消化原料"}`。

无法判断时返回 `{"rule":"inbox","reason":"缺少日期或出处"}`。日期和出处缺失的内容不归档。
